Student Visual Hierarchy Documentation

Document the specific CSS strategies you implemented for at least 5 elements to establish visual hierarchy.

Target Element / Class Hierarchy Principles Applied Implementation Details & Design Rationale
.hero-title Size & Scale, Color & Contrast Set to 52px bold with a -0.5px letter-spacing, making it the largest text on the page. Placed inside a dark gradient hero section (#1a1a2e to #0f3460) with white text, creating maximum contrast so it commands immediate attention as the primary focal point.
.btn-primary / .nav-cta Color & Contrast Applied a high-saturation red (#c0392b) to the primary call-to-action buttons against the dark hero background and dark header. This red carries the highest visual weight on the page, drawing the eye to the most critical interactive elements. The secondary button uses a transparent background with a subtle white border to recede in importance.
#hero Negative Space, Reading Patterns Given 100px top and 90px bottom padding to create generous breathing room that frames the hero content. The centered layout with a large gap (40px) between description and buttons guides the eye in a Z-pattern from the badge at top-left, across the title, down through the description, and toward the action buttons.
.card-grid / .course-card Alignment & Grids, Proximity & Grouping Used display: grid with grid-template-columns: repeat(3, 1fr) and gap: 30px to create a three-column aligned layout. Each card uses flexbox with flex-direction: column and consistent 32px/28px padding to group the category badge, title, description, metadata, and link into a cohesive unit. The 30px gap separates unrelated cards while keeping related content within each card tightly grouped.
#announcements Proximity & Grouping, Typography Hierarchy Styled with a dark (#1a1a2e) background that visually groups all event items together. Each list item uses a 3px left border in red to create a visual timeline. The heading uses a gold color (#e8d5b7) at 22px bold while body text is 15px in muted gray (#c8c8d4), establishing a clear two-level typographic hierarchy within the component.
* (universal selector) Typography Hierarchy Applied Garamond serif font across all elements using the universal selector to establish a consistent typographic identity. Combined with clear size progression — hero title at 52px, section titles at 36px, card titles at 21px, body text at 15px, and meta labels at 12px — this creates a five-level typographic hierarchy that clearly distinguishes content importance.
#site-header (sticky) Reading Patterns, Color & Contrast Made the header sticky with position: sticky and z-index: 100 so it stays visible during scrolling. The dark background (#1a1a2e) with a box-shadow creates depth separation from the content below. Flexbox with justify-content: space-between places the brand logo on the far left and navigation on the far right, establishing the starting point of the Z-pattern reading flow.
